## 选人 → 检索路径

1. 点省略号 → `openUserPicker` → `fetchUsers(session.accessToken, { q: pickerQ })`
2. 点选用户 → `filters.userId = user.userId`，`selectedUserLabel = userLabel(user)`，关闭层
3. 点「检索(S)」→ 原 `search()` / `loadPage()` → `fetchUserOperationLogs(..., queryParams())` 带 `userId`
4. 「清除」后 `userId` 为空 → 查询不按用户过滤（与基线一致）
5. 迟到响应：`pickerRequestId` 丢弃过期 `fetchUsers` 结果；关闭时递增 id，避免重开幽灵列表

## DOM / 行为探针（实现侧）

- 主输入：`readonly` text；**无** `input[type=search]` 作为用户主路径
- 省略号：`button[aria-label=选择用户]` 可见「…」
- 薄层：`#user-operations-user-picker[role=dialog]`；Esc 关闭并回焦省略号
- 清除：dialog 内「清除」；无选中时 disabled
