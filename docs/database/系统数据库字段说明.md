## 阅读约定

- `可空=否` 表示 `NOT NULL`，`可空=是` 表示 `NULL`；没有列级 `DEFAULT` 时记为“无”。`rowversion` 是 SQL Server 自动生成的并发版本字节值，不是日期时间。
- 列表中的类型、长度、精度、NULL 和默认值均按迁移原文记录；键、索引与 CHECK 在后文汇总。没有声明的 FK、CHECK、默认值不推定存在。
- 敏感类别：`个人信息`、`个人信息（敏感）`、`医疗健康`、`财务`、`账号凭据`、`权限配置`、`审计/网络标识`、`业务记录`、`主数据`、`系统元数据`。类别用于数据分级参考，不替代机构正式安全分级。
- `待确认` 表示迁移只定义了兼容/扩展字段，且当前迁移、接口契约及模型资料未证明其业务含义或取值映射；不应据字段名自行赋予规则。
- 后文将 **DDL 约束**（由 SQL Server 强制）与 **应用/接口逻辑**（需服务实现保证）分开。接口枚举不能据此视作数据库 CHECK。
