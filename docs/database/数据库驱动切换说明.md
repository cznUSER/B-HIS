# B-HIS 数据库驱动边界

运行时由 `internal/store.Open` 根据 `Database.Driver` 选择持久化驱动，应用层只接收 `port.StoreSet` 中定义的业务端口。

- `sqlserver`：当前唯一启用的生产驱动，使用 `internal/store/mssql.Driver`，连接失败直接返回错误。
- `dameng`：预留切换接口，使用 `internal/store/dameng.Driver`。本版本返回明确的未实现错误，禁止静默回退到 SQL Server 或内存库。
- `memory`：仅供 `internal/store/memory` 单元测试直接实例化；运行时工厂拒绝该驱动，网站也不会进入内存 Mock 模式。

以后接入达梦时，只需在 `internal/store/dameng.Driver.Open` 中返回完整的 `port.StoreSet`，并保持端口契约、事务边界、审计和幂等语义一致；无需修改 `internal/app` 或 HTTP 层。
